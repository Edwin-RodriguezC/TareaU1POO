Este repositorio contiene la solución a la guía de 50 ejercicios de programación en C#.

La idea de esta guía es repasar y dominar los conceptos clave de programación estructurada, desde lo más básico hasta el manejo de colecciones y listas.
Para correr estos ejercicios necesitas:
-.NET SDK (versión 6.0 u 8.0 en adelante).
 - Un editor como Visual Studio
-Escribir dotnet run para ejecutar los ejercicios.
